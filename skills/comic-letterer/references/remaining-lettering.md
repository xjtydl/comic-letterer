# 从语义选择到真实排字

使用程序前由AI/排字者完成语言和剧情判断。以下是实际执行方法，不把中文词义判断、自动分割画面或全部37项传统伪装成确定性算法。

1. 从冻结文字选出不可拆的词组：如“妈妈”“封闭灯室”。写入`keep_together`的Unicode字符范围；按标点与语义安排`breaks`。先移动/扩展气泡，再考虑`line_widths`；单行横向比例仅在0.9–1.1内少量调整。
2. 逐项分清叙述者/思想/说话/设备/环境声。思想不等于心灵通信；咳嗽必须有发声事件；唱歌必须有歌词情节。没有发生的声音不新增。两页“最后一张票”是这一判断的实页例子。
3. 中文不套用英文横杠I、全大写或强制粗斜体。英文交接核对代词I、引号跨度、外语标记和书籍约定；中断/拖尾/省略语义依剧本，数字与注释查上下文。语言建议只提出待核对项，不覆盖原文。
4. 叠放策略：同人连续语句优先明确连泡；插话保留读序和各自声源；人物遮挡用明确前景蒙版并检查文字；普通相压不当作自动许可。`overlap_with`显式指定后发气泡在前，不能与连泡混用，正文相压仍拒绝；`cross_border`允许指定方向的壳跨边，文字仍需留在所属格内。贴边裁切用`butt`，不能同时跨边和裁切/画外裁切。
5. 手修轮廓：拖动归一化三次曲线控制点，保持闭合、中心在内部、无自交，实看尾根与每行留白。平边用于形状需要，不改变普通/耳语的声音类别。任意病态凹轮廓仍需视觉检查。
6. 画内字先标真实承载面的四角；`surface`按TL/TR/BR/BL投影。母版保留Unicode；可视路径是派生输出。简单Latin/CJK已验证，复杂脚本不能靠逐字转路径冒充塑形。
7. 声音设计先记录`event/source/material/intensity/duration`，再定字形/排列/色彩。琴声不能因展示材质功能变成撞击巨字。有限磨损只用于适合的表面/声效；反复回到900px阅读图检查。
8. 原创字形：先定baseline、cap height、advance和用途，用`font-build`保留笔触与压力，检查重复字/字偶/替代字。HOME门牌证明小字库工作流；制作完整中文/拉丁家族仍需逐字校样，不从商业字体提取“手写样本”。
9. 复核完整页：遮住文字看动作是否成立；打开文字看读序、认主、源字和留白；对照前后版本说明具体修法。单元测试和读取教程不等于实页或用户验收。

37项传统的完整主题目录与各来源状态保留在仓库45模块索引中。已有剧情证据见v02–v06验证记录，不能把未出场的语言/声音写成已验证。
