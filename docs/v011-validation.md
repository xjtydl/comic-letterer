# v0.11：自然轮廓、淡染与实际剧情

用户要求继续优化程序气泡/文字，让其融入画面。沿用《最后一张票》已批准原画与十条冻结文字，实际制作两页和八格长条。本例为既有八格片段的排字验证，不是制作分支新V04全文成页；没有调用图像模型或Qwen。

## 实现与实际修订

核心新增`organic`轮廓参数（不对称、饱满度、种子），保留对白、耳语、思想、弱声的声音区别。字面/声音标记留白和尾根交点使用实际轮廓。普通organic未给profile时保留旧几何；不冒称拟真人笔压或任意手绘轮廓。

`appearance.wash_color/wash_opacity/wash_angle`把纸底实色向环境色淡染，泡身、尾巴、思想点、同组连泡连续。不让背景透过文字，不对文字和原画加滤镜。与纸纹组合时，淡染不会每128像素重新开始。颜色与方向仍由AI/排字者依据画面选择，没有自动取色/光照估计。

编辑器有实际可调控件，可保存重载；继承参数不丢失。全书规则/受前值保护的修订支持两组参数，旧整对象appearance规则补齐默认值后比较，避免新字段带来无谓漂移。短曲尾与无框旁白使用既有功能，不算新算法。

完整剧情中的修订：

- 咳嗽泡向声源靠近，曲尾缩短/加宽；思想泡采用不等节奏云瓣；弱声与歌唱尾巴由细直针形改为曲线收尖。
- 第一轮实际路径检查报“这首曲子……”泡文字留白不足，保存诊断后扩大350×150至370×168；未缩字、未改词。
- 耳语初次曲尾过细，实看后加宽根部并修控制点。暗背景上保留清楚的虚线节奏。
- 实看第二页发现结尾大色块仍抢画面，题头与结尾改为已有floating类型、editorial旁白来源，文字落在原图负空间；原文、字号、原画不变。

已查看中间1024宽双页、最终600宽双页，以及390宽长条的全部八格。原有分格、保护区、声源、说话者、声音语义与顺序保持；十条Unicode逐项核对，SVG嵌入原画与源PNG字节相同。两页报告0问题，全书正常与漂移副本分别验证。390/600宽浏览器均解码五张图，新旧双页可展开，无横向溢出或JS错误。
