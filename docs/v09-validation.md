# v0.9 剧本富文本交接与实际成页

本轮推进A02剧本/文字交接，并更新D03/E05。沿用comic-production-entry、comic-lettering的script-type-and-output，以及既有布局与视觉语言：画面说明和台词分开；明确页/格/字项/说话者/声线；强调落到真实字体；原文、工程与导出画面三处核对。构图、原画及演出沿用，不重新生成角色或改场景。

## 已实现的交接范围

`script-import` 读取UTF-8的语义HTML交接表，每条含page/panel/id/order/kind/speaker/voice/text/note。`strong/b`、`em/i`及组合转换为Unicode码点范围的bold/italic/bold_italic字体角色。HTML实体解码，原文空格和标点不归一化；表外文档内容不作为台词执行，说明留在交接记录。

与现有书籍工程逐项核对全部20个稳定ID及页/格/顺序/类型/说话者/声线；缺项、重复、额外项、错误元数据、冻结文字不符拒绝。原有复杂强调不被新HTML默默覆盖。几何、断行、词组保护、声源坐标、原画和规则保持原样；仅无文字且无冻结值的明确空槽可接收新台词。导入新增原文冻结，仍须用真实资产渲染。

支持的是明确交接表，不是任意网页/Word/PDF自动理解。CSS字体样式不推断，单元格内不支持的标签、属性、换行和不平衡标记拒绝，不能默默丢失格式。表外页面CSS不决定语义。字体必须由当地合法资产配置，不伪造粗斜体。

## 真实剧情验证

采用《最后一张票》中英文两页共四页、20项台词。交接表是 `examples/theatre-handoff.html`，版面沿用 `examples/theatre-book.json` 指定的已验证900px页。新编写的强调仅为“妈妈／Mum”，突出信使认出母亲曲子的剧情转折，冻结文字不改；这是本轮授权制作中的排字选择，不冒称用户逐字视觉验收。

首次渲染发现旧英文资产表没有bold角色，程序明确拒绝，保留日志。配置真实Arial Bold后重渲染；中文采用已有Noto Sans CJK Black。完整四页各0问题，实际查看确认强调可见，思想与耳语仍分开，其他声线、钢琴拟声、旁白、脸和票据保留。英文第二页和中文第二页的PNG与v0.6逐字节一致；第一页只增加指定强调。

核对20项原文和expected_text一致，除了新增强调之外的字项字段逐项不变；SVG嵌入原画字节不变。动作/声音说明没有漏进台词。另在真实交接表副本把“声音”改为“记忆”，命令以冻结文字不符拒绝，未产生输出目录；原表与原工程保持。

交接核对HTML中的两处强调已打开检查，连续校样HTML四图已加载并查看。导入报告明确 `rendered:false`，不会把表格导入成功冒称成页通过。原HTML字节作为 `manuscript-source.txt` 留存，输出核对页从解析内容安全重建，不执行原文件中未支持的页面内容。
