Blambot 与 Comicraft / Balloon Tales 的所有已发现相关内容全部纳入，共 **45 个能力模块**。范围包括构图、绘画、整本制作与未来 AI 训练。

1. **当前：先补完气泡与文字**，用完整剧情漫画检查读序、文字、声源和画面关系。
2. 接着推进其余构图、绘画、整本制作模块，复用已有项目 Skill。
3. 训练体系保留范围，但没有训练任务、数据或指标就不得写成已训练。
