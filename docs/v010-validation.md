# v0.10 气泡材质与边缘：程序路线实证

2026-11-06。用户明确两条路线都指**气泡＋文字**：程序生成、由图像模型直接生成。本轮只优化程序，既有角色/场景原画和十项文字冻结；没有图像生成或Qwen调用。沿用已读制作入口、布局、视觉语言及排字Skill，布局与演出保持，以实际声音选择纸色、边光和耳语断线。

## 从分支操作变为核心能力

`balloon_finish.py`新增受校验的`appearance`，可由字项或页样式指定；不是照搬r02的故事ID后处理。

- 页坐标纸纹贯通泡身、尾巴、思想点、声源标记和连段。同材质复用同一纹理，尾根重叠不重新起纹理或叠深。正文/符号墨线与背景不套纸纹滤镜。
- 柔光由整个气泡轮廓生成，放在不透明泡面之下；正文保持清楚。颜色、半径、浓度可调，不自动让每种声音发光。
- 中心耳语虚线部分落在浅纸面，深背景上也可辨；尾根和连段两端遮去穿过的前景描边，避免横线接缝。
- 编辑器加入底色/墨色/边线/纸纹/柔光/耳语控件；保存、重载和继承参数可继续修改。显式禁用后切换声音类型也不会恢复被关闭的材质。
- 全书规则及带旧值保护的修订接通`appearance.*`，可检查和修改纹理/柔光漂移。缺省仍为旧纯色输出，`null`关闭继承效果。

确切字段及范围见[契约](contract.md)。`paper/glow`不再只存在于分支SVG脚本；原r02脚本和结果作为历史证据保留。

## 《最后一张票》真实结果

沿用r02的两页原画、十项文字、字号、声源和格位。普通泡改暖灰纸色及棕墨；幽灵/思想泡加入克制柔光；耳语从平边矩形改自然椭圆，以减少卡片感。首次整页检查发现浅色轮廓使精神声线小标记偏淡，最终主题将这条墨色调回较深的`#8A7968`，柔光颜色另控。正文、人物、琴键和票据没有被重绘。

两页直接由核心编译成SVG并渲染，**没有渲染后修改SVG样式**。随后用原r02的完整格位变换拼成八格长条；重排只做引用、变换、裁切和ID去重。保留JSON、样式、SVG、600/1024页图、600/390长图和单文件阅读页。两页报告均0问题；390宽正文约20.8—25像素。

已查看双页、第一页1024图和390宽全部八格；耳语尾巴仍清楚归属青年，思想点归属与字区保持，整段入场—认曲—唱歌—消散—黎明留票连续。纸色较r02收敛、泡身尾巴材质一致，但程序云泡仍较规律、部分尾巴仍偏细长；本轮不声称与原生生成的笔意完全相同，也不代签用户视觉验收。

十项`text/expected_text/SVG Unicode`逐项一致，原画嵌入字节不变。两个完整页组成的样式检查通过；另存副本把幽灵泡纸纹强度改为`.28`并遗漏柔光，明确报告样式漂移。正式页未被故障副本覆盖。
