## 本轮完成标准

每项有可编辑参数、无效输入拒绝、保存/重载、真实字形和轮廓检查；首字不能重复或丢失源字符，后文要实际绕排。机械虚线必须多层构成，不能拿耳语虚线替代。齿数随周长改变以维持密度。卷轴折返线不可压正文。实看整页及局部，原文和原画逐字节核验。自动报告与助手实看均不冒称用户验收。
