## 制作方法的实际调整

1. `comic-production-entry`允许原生图文作为正式制作路线，不要求每次先无字图再程序排字；保留本项目用户的优先方向。
2. `comic-visual-language`新增原生/独立排字/混合选择参考：纸色明度、边缘与材质连续性、声线柔光、虚线对比、标题与结尾留白。
3. `comic-lettering`明确其几何与活字规则适用于已选择独立排字的任务；正确原生文字无需全部重排。
4. 仓库携带的 `comic-letterer` Skill补同样的选择与分支边界，核心已有fill/stroke/text_color可用；不发明paper/glow等未实现JSON字段。

Skill负责可复用判断，程序负责可重复操作；不以目前程序轮廓限制生成模型的画面设计。原生字仍须逐字检查，栅格字不能冒称活字；既有角色/建筑/审定对白的授权边界保持。

## 核验与证据

项目复核脚本：`docs/production/review_last_ticket_branches.py`。它只读两个分支，输出独立对照阅读页和`audit.json`，不覆写原r01/r02成品。结果入口由项目交接索引链接。

- 对程序版以ID和顺序核对两页十项原文、expected_text及SVG Unicode，连同两分支文字母版匹配检查。
- 核对原画嵌入字节、原JSON哈希、固定v0.7引擎哈希、八格顺序及SVG引用；已有布局报告为两页0问题，不把读报告写成新编译。
- 阅读页内嵌完整图片，不依赖相邻文件；390和600宽隔离浏览器检查三种版本切换、双页展开及图片解码。
- 程序滤镜与图片融合的结论来自实际读图和脚本；自动核验不代替视觉验收。r01栅格中文字已目视核对，不能由旁边JSON证明像素文字编码正确。
- 未跑新的核心测试，因为核心代码没改；201项仅保留为v0.9既有基线。没有训练任务、数据集或指标，不改训练状态。

当前仍未满足：r01精确段内滚动停顿与部分声音标记、原生局部修改的框外像素锁定、指定GPT Image 2.5后端身份；r02全泡材质连续性、自然手绘边缘、可移植滤镜和统一样式参数。本轮不将这些列为已实现。
