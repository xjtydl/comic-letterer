# v0.8 布局方案的实际漫画校样

开发对话推进A04/A05/A06；GPT Image 2.5直接生成长条的实测由另一个制作分支负责。本轮不是该模型的输出评测，也不声称重新绘制了漫画。

查用comic-production-entry、american-comic-layout的layout-patterns/preflight、comic-visual-language及comic-lettering。选用方法：保持真正的剧情信息变化；先放真实台词；在最终显示尺寸复查；整页先被扫视，滚动分段改变信息暴露，不把格数或像素间距换算为秒数。

沿用v0.7《最后一张票》中文第一页，四格信息依次是抵达剧院、入内咳嗽、幽灵等待结尾、认出母亲的曲子并轻声回应。原画、台词、声源、保护区和格内相对位置冻结。

两个有不同目的的方案：

- 整页网格：600×900，保留人物联系和同页信息的整体扫视；不承诺隐藏下半页幽灵。
- 分段阅读：600×3840，各格等比完整放置，通过分段显示先读抵达和入内，再遇见幽灵。不是把两个整页直接拼接，不截掉原文、脸或道具；也不是重新设计过景别的正式全新画稿。

程序职责：每格恰好一次且按原叙事顺序关联；按槽位等比适配；排版与原画同步移动；检查重叠、明显读序倒置、源格裁掉的文字/壳/尾尖和实际字号。绘画焦点、复杂插格读序、未知画外空间和读者理解仍需人工/AI实看。

故障对照将幽灵格缩小并放到反应右侧：程序应报缩字及读序冲突，完整画面应显示问题。修复后保留两个不同阅读结构，不给其中一个自动颁发“更好漫画”结论。
