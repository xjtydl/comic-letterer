# v0.7：全书修订与实际阅读对照

沿用《最后一张票》中英文两页的剧情、四格构图、人物/场景、原画、声源与冻结文字，不新增生图。查用 comic-production-entry、american-comic-layout、comic-visual-language、comic-lettering 的文字交付参考，以及 comic-letterer。采用的方法：实际阅读尺寸决定文字试排；先字后泡；保留声线差异和旁白层级；修改保留母版与前后图。

本轮问题：v0.6在900px阅读宽度验证，通过检查不代表缩至600px仍够读。本轮制作600px阅读版本，沿用工程18px最小字面阈值（项目选择，不是通用标准），正文/旁白试32px原稿字号。物理门牌和安静钢琴拟声保留叙事比例。所有变动写入明确的页/项/字段及前值/后值，不自动把所有字缩放成同一尺寸。

开发目标：`book-revise` 根据固定输入哈希和明确修订计划，写出新版本、前后完整漫画、改动清单和对照阅读HTML。旧稿及原画不覆盖。旧值不符、陈旧来源或越权改文拒绝；合理例外不自动消除；新版本仍要过原有排版、全书规则和字体身份检查。

验证顺序：先生成600px原字号诊断，再增加字级并查真实溢出，针对受影响项调整换行/壳尺寸；逐页查看完整中英文漫画及前后对照。保留失败稿，记录具体修正，不把机器通过当成用户验收。另以故障副本验证拒绝陈旧计划、原文修改、规则漂移，以及继承样式的定点修改不会串改其他项。

不适用：重画人物、重新分格、强加卷轴/锯齿或扩大琴声；这些不能解决小尺寸阅读问题。整本出版、多人实时协作、自动审美验收和训练任务仍非本轮范围。
