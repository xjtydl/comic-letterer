# v0.7：全书修订以实际600px漫画验证

本轮接续D04全书样式检查：将显式修订计划落实为新版本，生成修订前后完整漫画对照。范围是已有四页中英文《最后一张票》，不把它冒称长篇出版全流程。方法与理由见 [页计划](v07-page-plan.md)。

## 实际问题与修正

900px验证不能替代600px阅读。保留原字号缩到600px时，中文正文约15.2px、英文约14.1px，共16项低于工程既有18px阈值。阈值是项目选择，不是两站规定或可访问性认证。

将16项正文/旁白改为原稿32px（600px显示约18.75px），保留物理招牌和安静琴声的字号。随后实际遇到：

1. r1：原有弱声逐行宽度超过大字号下的可用壳宽，命令拒绝无效配置并清除临时输出。放大弱声壳，重新给两行宽度。
2. r2：出现17项溢出、标记越界或相邻文字遮挡。完整诊断稿保留；英文标题、心灵对白、思想/耳语和歌唱/结尾均不能只放大字。
3. r3：扩壳、按原词句重排后，仍有3项遮字/耳语行宽错误。中文思想之后的耳语下移；英文耳语加宽并下移，保留独立叠放而不合并声线。
4. r4：机器0问题，但实看英文歌唱泡的尾巴仅剩小尖角，归属不够清楚。上移歌唱泡并调整宽高，恢复尾巴可读长度；没有改声源保护、人物或台词。
5. final（r5）：四页各600×900，完整阅读检查通过，自动检查0问题。歌唱改为三行，英文结尾两行；中文“妈妈”保持词组完整，人物脸/票据仍清楚。助手自检，不代称用户验收。

## 实现

`book-revise` 接收当前书籍、资产映射与修订计划。计划记录所有页字节哈希、规范化书籍哈希，以及35项页/文字字段变动和10项明确的规则期望变动。每项含前值、后值、可观察的修改理由。

- 拒绝陈旧来源、错误前值、重复目标、未知项、无理由以及改动原文/角色/声源等不支持字段。
- 定点改动继承样式时保留嵌套同级设置，不改同样式的其他字项。
- 原样保留规则选择条件和精确例外；不为了干净报告自动改规则、删除例外或忽略警告。规则更新须另列计划。
- 写入新版本，不覆盖输入；前后各渲染完整页面，记录源文件/原画/字体，生成同宽对照HTML。渲染异常清理暂存，排版问题则保留明确诊断稿。
- 输出保留可编辑页、SVG、PNG、前后规则、计划和结果；用户验收为`not_recorded`。没有增加例行审批闸门。

## 核验

完整本地 **175项测试通过**，Chromium启用（80.74秒）。新增11项涵盖陈旧计划、冻结文字、继承嵌套设置、已有精确例外、规则漂移、实际前后PNG差别和失败暂存清理。安装包、发布和CI状态见项目交付记录。

四页原文、分格、保护区不变；SVG嵌入的原画字节不变。修订前四张PNG逐字节复现v0.6。600px对照HTML加载8张完整页面，600/900显示宽度控件实际操作检查。切到450只代表预览，不宣称450px字号也通过。

NAS `v07/` 保留原字号600px诊断、r1日志、r2完整失败对照、r3问题、r4机器通过而视觉有问题的稿和 `revision-final/`。最终入口是 `revision-final/index.html`，连续新版是 `revision-final/after/index.html`。
