## 0.5.0 — 2026-11-05

Adds mechanical three-stroke/notched balloons, arc-length sawtooth and flame contours with controlled density, scroll captions with reserved fold space, and real-font dropped initials with actual multi-line wraparound. All new operations have editor controls, persistence and PNG export coverage. Verified on the original six-panel Lightkeeper Chinese and English story, retaining exact words and unchanged artwork.

After these five operations passed, adds read-only `book-check` with explicit style rules, exact documented exceptions, stale/unmatched warnings and frozen-word checks. This starts D04 metadata consistency without claiming complete book production.


## 0.4.0 — 2026-11-05

Adds measured bounce/wave dialogue baselines, independent emphasis baseline shifts, subtle organic speech contours and tattered caption borders. Editor controls, saved JSON and SVG glyph positions share the same fields. Original narrative-page validation caught and corrected a contour overflow while preserving wording and artwork.

Archives the two-site research, source-level reading states, 45-module scope, method notes and continuation index. This is a further lettering increment; OpenType, mechanical multi-layer balloons, scrolls/drop caps, full-book production and AI training remain open.


## 0.3.0 — 2026-11-05

Adds actual-font emphasis runs and local font maps, tracking/controlled horizontal scale, explicit phrase protection, reusable styles and caption source types. Tail roots, width, length, source gaps and curves are independent; a continuation can own the identifying tail. Optional short-tail and manually marked ink-edge warnings. Adds rough contours/tails, double outlines and explicit voice marks. Editor exposes these controls and bounded text-first contour fitting while retaining frozen wording.

Validated with two continuous Chinese Echo Station pages and a real-font English treatment of page 2. Breath/music/telepathy decorations have unit coverage but no narrative acceptance claim. Complex shaping, wavy song baselines, full book management and prepress remain open.


## 0.2.0 — 2026-11-05

Adds the loopback visual editor, immutable frozen-word validation, drag/resize/source/curve handles, undo/redo, versioned saves and SVG/PNG export. Typography now supports independent break offsets, balanced flow, measured size emphasis and separate display fonts. Geometry adds TV contours, panel-butting, off-panel edge tails, squinks, curved interruption joins and polygon masks. SFX adds hollow fill, stepped depth, arc and per-glyph transforms.

Validated on the original five-panel Echo Station story, a separate interruption treatment, browser interactions, rendered pixels and a private unchanged-art regression. This is not prepress certification or a complete script-to-comic editor.


## 0.1.0 — 2026-11-05

First independent library and CLI release: exact Unicode text, font measurement, initial voice presets, curved/point tails, consecutive same-speaker joins, rotated multi-outline SFX, explicit/candidate placement, editable SVG and optional direct-from-vector PNGs. Includes layout reports, tests, original Chinese specimen inputs, a portable Skill and a tutorial coverage ledger.

This is a staged core release. Unsupported geometry, typography, prepress and integration features are tracked in `docs/coverage.md`; a clean report is not a visual acceptance certificate.
