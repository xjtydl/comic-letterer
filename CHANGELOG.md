# Changelog

## 0.2.0 — 2026-11-05

Adds the loopback visual editor, immutable frozen-word validation, drag/resize/source/curve handles, undo/redo, versioned saves and SVG/PNG export. Typography now supports independent break offsets, balanced flow, measured size emphasis and separate display fonts. Geometry adds TV contours, panel-butting, off-panel edge tails, squinks, curved interruption joins and polygon masks. SFX adds hollow fill, stepped depth, arc and per-glyph transforms.

Validated on the original five-panel Echo Station story, a separate interruption treatment, browser interactions, rendered pixels and a private unchanged-art regression. This is not prepress certification or a complete script-to-comic editor.


## 0.1.0 — 2026-11-05

First independent library and CLI release: exact Unicode text, font measurement, initial voice presets, curved/point tails, consecutive same-speaker joins, rotated multi-outline SFX, explicit/candidate placement, editable SVG and optional direct-from-vector PNGs. Includes layout reports, tests, original Chinese specimen inputs, a portable Skill and a tutorial coverage ledger.

This is a staged core release. Unsupported geometry, typography, prepress and integration features are tracked in `docs/coverage.md`; a clean report is not a visual acceptance certificate.
